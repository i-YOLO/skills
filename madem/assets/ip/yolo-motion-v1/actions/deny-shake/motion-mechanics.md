# deny-shake 动作力学

## 语义

用于口播中的“不对、不是、不要、否定、无法通过”等轻量否定。只做一次克制的左右摇头，不做全身晃动。

## 固定与传导

- 固定脚底基线、骨盆和躯干，双手始终自然放在外套口袋内。
- 表情先从中性转为轻微否定：嘴角收平、眉形轻收；随后眼神先向动作方向偏移。
- 头颈围绕颈根做一次小幅侧转：中位 → 第一侧 → 经过中位 → 第二侧 → 回中。
- 单侧头部偏转不超过约 8°；肩部只允许极小惯性跟随，骨盆和鞋底不得移动。
- 回中时略过中位后小幅回弹，最终保持明确但克制的否定表情。

## 两条母带

- `a`：中性 → 否定表情出现 → 第一侧摇头 → 加速经过中位 → 接近第二侧。
- `b`：前两姿势严格复现 `a` 的最后两姿势 → 到达第二侧 → 回中 → 微过冲 → 回弹 → 稳定落定。
- 每条母带 8 个从左到右的连续完整全身姿势；人物数量必须恰好为 8。

## 关键姿势与预算

1. 中性站姿。
2. 眼神与否定表情先行。
3–4. 第一侧转头。
5–6. 回穿中位。
7–8. 接近第二侧（交接）。
9–10. 复现交接姿势。
11. 第二侧极值。
12–13. 回中。
14. 轻微过冲。
15. 回弹。
16. 稳定否定表情落定。

目标保留全部 16 个逻辑时刻；重复交接姿势在时序中作为缓冲姿势使用，最终帧至少保持 12 tick。

## 视觉约束

- 无道具、文字、符号、阴影、地面、网格、分栏、残影、速度线或运动模糊。
- 背景必须是完全均匀的 `#ff00ff`。
- 身份、服装、发型、眼镜、橙色鞋、配色、线条粗细和人物比例严格跟随对应朝向身份母版。
- 左右朝向分别生成，不使用镜像。
