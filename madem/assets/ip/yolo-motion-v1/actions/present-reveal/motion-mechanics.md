# present-reveal 动作机制

## 语义与时长

- 语义：人物把观众注意力引向画布内侧，以自然展开的掌心完成“这里 / 请看 / 接下来”的介绍。
- 源帧率：12fps。
- 目标逻辑姿势：20 个；由 `a / b / c` 三条 8 姿势母带组成，相邻母带重叠 2 姿势。
- 播放模式：one-shot-with-settled-hold；最终落定至少 12 tick。

## 固定部位

- 双脚鞋底基线、骨盆和躯干中心锁定。
- 非刻意重心位移不超过人物高度 3%，头部转角不超过约 8°。
- 非展示侧手臂保持自然放松，不随展示手臂大幅摆动。

## 动作传导

1. 眼睛先看向画布内侧。
2. 头颈轻微跟随视线。
3. 内侧肩膀松开，肘部从身体旁抬起。
4. 前臂向画布内侧展开。
5. 手腕最后打开，手指自然并拢，掌心朝上且略朝观众。
6. 展示位有一次很小的惯性过冲，再回到清楚稳定的介绍姿势。

## 朝向规则

- `right`：人物面向画面右侧，掌心和前臂指向画面右侧的画布内侧。
- `left`：人物面向画面左侧，掌心和前臂指向画面左侧的画布内侧。
- 左右分别生成，不做代码镜像。

## 母带阶段

- `a`：中性站姿 → 视线先行 → 肩肘启动 → 半展开掌心。
- `b`：复现 `a` 最后两姿势 → 前臂继续展开 → 手腕打开 → 完整介绍姿势。
- `c`：复现 `b` 最后两姿势 → 轻微过冲 → 小幅回弹 → 稳定落定。

## 验收重点

- 手掌必须明确朝画布内侧，不能朝身体、朝下或变成指点手势。
- 手指数量与结构稳定，不能出现粘连、额外手指或单帧断肢。
- 伸臂过程中躯干不得被透明轮廓宽度带着反向漂移。
- 三条母带的两个交接姿势需在比例、鞋底基线和肢体角度上连续。
