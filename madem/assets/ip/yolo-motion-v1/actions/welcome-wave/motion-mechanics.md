# welcome-wave 动作机制

## 语义与时长

- 语义：人物看向观众，抬手做两次友好、克制的小幅挥手，然后自然回落。
- 源帧率：12fps。
- 目标逻辑姿势：20 个；由 `a / b / c` 三条 8 姿势母带组成，相邻母带重叠 2 姿势。
- 播放模式：one-shot-with-settled-hold；最终落定至少 12 tick。

## 固定部位

- 双脚鞋底基线、骨盆和躯干中心锁定。
- 上臂抬起后基本稳定；两次挥动主要由腕部和前臂完成，不以整条手臂左右扫动。
- 非挥手侧手臂保持自然放松。

## 动作传导

1. 视线先回到镜头，表情轻松友好。
2. 肩膀轻提，肘部弯曲抬起前臂。
3. 手掌到达脸侧稍外位置，掌心朝观众。
4. 第一轮：前臂极小幅跟随，手腕外摆 → 回中 → 内摆。
5. 第二轮：手腕回外 → 回中 → 内摆，幅度比第一轮略小。
6. 手腕回到中性，前臂回落，最后稳定站定。

## 朝向规则

- `right` 与 `left` 都保持各自身份母版的真实朝向，挥手手掌朝观众。
- 两个朝向分别生成，不做代码镜像。

## 母带阶段

- `a`：镜头视线 → 肩肘抬臂 → 掌心到脸侧挥手准备位。
- `b`：复现 `a` 最后两姿势 → 完成第一轮腕部挥动 → 进入第二轮。
- `c`：复现 `b` 最后两姿势 → 完成第二轮腕部挥动 → 手臂回落 → 稳定落定。

## 验收重点

- 两次挥动必须能从连续姿势中读出，且运动主要来自腕和前臂。
- 肩膀和躯干不能随手掌左右摆动；鞋底基线保持稳定。
- 掌心不能突然翻到背面；五指结构在相邻姿势间保持一致。
- 三条母带的两个交接姿势需在比例、鞋底基线和肢体角度上连续。
