# 逐帧人物动效生产与晋升

新建、扩展或修复 IP 逐帧动作时使用本规范。它定义视觉生产；真实口播词位绑定由 `$sync-explainer-video` 负责。

## 资产边界

- `madem/assets/` 是可复用生产资产的唯一来源。
- `sync-explainer-video` 只保存动作 ID、阶段、朝向、结果分支与词位，不复制生产资产。
- 项目目录保存未完成试做、生成母带和项目证据；沿用项目既有目录结构，不发明全局固定的试做根目录。
- 知识库可保存方案、决策、轻量预览、验收结论、资产索引和与项目绑定的候选证据，但不建立第二套全局复用资产库，也不作为渲染时依赖。
- 使用资产时，把组件和所需文件复制到视频项目并锁定 catalog/文件哈希。

## 开始前

1. 读取 `assets/registry.json` 和目标资产包 catalog。
2. 确定身份母版、左右朝向、结果分支、道具层和显示尺寸。
3. 写 `motion-mechanics.md`：说明固定部位、先行动作、跟随部位、惯性、遮挡、关键姿势和落定姿势。
4. 写逐帧动作预算；相邻姿势应改变相近的视觉量。

人物默认锁定脚底、骨盆和躯干。视线通常先行，头颈轻跟，肩、肘、腕和手指依次传导。头部转角通常不超过约 `8°`，非刻意重心位移不超过人物高度 `3%`。

## 连续母带

- 每条母带生成 `6–8` 个有序、分离、完整全身姿势。
- 大动作拆成多条母带；下一条同时绑定身份母版和上一条母带。
- 相邻母带保留 `2` 个交接姿势。使用交接姿势校准比例、基线和动作方向，再选取最终连续帧。
- 同一阶段整体失败时重做完整母带，不在不同生成批次之间补一张孤立帧。
- 左右朝向分别生成；只有身份、服装、光照和道具手性都允许时才可做经过批准的确定性镜像。
- 人物和道具分层生成。手持道具必须定义握持点、旋转、遮挡和惯性；接触后不得无解释地脱手。
- 使用纯色键背景；禁止文字、网格、阴影、速度线、残影、模糊和脱离人物的装饰效果。

## 拆帧与注册

1. 先清理键色，检查 RGBA、透明四角、隐藏 RGB 和边缘残色。
2. 优先按连通姿势组提取。只有确认所有姿势都在各自槽位内时，才使用等宽切分。
3. 若伸出的肢体跨过等宽数学边界，禁止直接切分；否则会把相邻姿势碎片带入当前帧。
4. 全动作只计算一次共享比例。不同母带存在整体尺寸差时，使用交接姿势计算一次“母带级”比例修正，禁止逐帧缩放。
5. 使用脚底、骨盆、躯干或明确记录的手工锚点注册。禁止按每帧完整透明轮廓水平居中；伸臂会改变轮廓宽度并导致身体反向漂移。
6. 保存每帧源边界框、目标边界框、锚点、比例、位移、tick、道具轨迹和 SHA-256。

接触表和预览必须使用固定画布比例渲染。不得为了“看起来整齐”而在预览中把每帧人物独立缩放到相同可见高度，否则会隐藏真实的 scale pop。

## 时序

- 默认源动画为 `12fps`，交付预览为 `60fps`。
- 运动阶段通常每张独立图显示 `1 tick`；缓入、缓出或微动作可显示 `2 tick`。
- 最终结果帧至少显示 `12 tick`，即 `1 秒`。
- 60fps 只按 tick 重复显示，不承担补间职责。
- 不得跳过关键姿势、做光流补帧或任意拉伸局部阶段来硬贴口播；需要改变节奏时优先调整阶段 tick 或重做动作。

## 自动检查

- 帧数、文件路径、尺寸、RGBA 和哈希完整。
- 透明四角、隐藏 RGB、键色残留和内部透明断层合格。
- 共享比例稳定；人物可见高度比例建议不超过 `1.02`。
- 1024px 源帧中，脚底纵向漂移建议不超过 `2px`；非刻意骨盆横向漂移建议不超过 `4px`。
- 手部—道具锚点误差建议不超过 `4px`；道具角度变化不得出现无解释的局部峰值。
- 比较相邻帧、阶段交接和循环边界。循环必须检查 `倒数第二帧 → 最后一帧 → 第一帧 → 第二帧` 的方向和速度，不以首尾图片相同代替运动连续。
- 全图平均差异只作为筛查证据；不得单独作为通过结论。

## 视觉验收

- 在 `#FAF8F3` 背景下以 `280px`、`320px`、`380px` 检查。
- 检查身体漂移、比例跳变、五官漂移、服装变形、颜色闪烁、碎片、裁切、手指异常、道具脱离和单帧故障。
- 检查准备、关键动作、回弹、结果和落定是否一眼可读。
- 检查阶段交接和循环边界；自动检查通过但肉眼有明显顿挫时仍判失败。
- 输出定帧表、浅暖白合成预览和 60fps MP4；生产帧必须是独立 RGBA，不使用拼接图。

## 入库与状态

### 项目试做

允许缺少部分朝向或分支，状态保持 `candidate`，留在项目目录。不得被资产注册表默认选择。

### Skill candidate

只有满足以下条件才能复制到 `madem/assets/`：

- 所有规定朝向与结果分支齐全。
- 资产包自包含，catalog、帧、道具、组件、预览和报告路径完整。
- 技术检查与人工视觉检查通过。
- 所有文件有 SHA-256。

### project-proven

至少一次真实成片使用，完成逐秒、事件帧、同步和用户验收后晋升。

### library-approved

跨项目复核可复用性、无专有依赖且没有暴露新的连续性问题后晋升。

更新 pack catalog 的状态与证据后，再同步更新 `assets/registry.json`。不得只改注册表状态。

新增或晋升 pack 后运行：

```bash
python scripts/validate_asset_registry.py \
  --registry assets/registry.json \
  --out <project-dir/asset-registry-validation.json>
```

## Catalog 最低字段

- pack ID、schema 版本、状态和身份母版。
- 动作 ID、语义、朝向、结果分支和播放模式。
- 源帧率、逐帧路径、tick、阶段节点、循环范围和落定帧。
- 画布、人物占位框、脚底锚点、推荐显示高度和安全区。
- 道具文件、握持点、位置、旋转、透明度和遮挡规则。
- 文件 SHA-256、生成来源、验证报告和真实项目证据。

## 失败处理

- 拆帧产生碎片：改用连通姿势组，不先重生成。
- 身体随伸臂漂移：改用解剖锚点，不按透明轮廓居中。
- 母带交接比例跳变：用交接姿势做一次母带级校准；仍失败则重做下一条完整母带。
- 相邻动作跨度过大：增加真实姿势或重分动作预算，不增加重复 tick 掩盖。
- 五官或服装漂移：重做完整失败母带并加强身份参考。
- 指标通过但播放生硬：以正常尺寸视觉验收为准，继续修复。
