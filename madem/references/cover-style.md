# AI 知识讲解高密度手绘封面

仅作为 AI 知识讲解类内容的默认封面预设，不强制用于其他 `madem` 项目。

## 风格

- 皇家蓝、深蓝、白色和橙色为主色。
- 使用 YOLO IP 作为主要视觉主体，采用蜡笔、手绘线稿和高密度信息板风格。
- 主标题必须醒目、短、可在缩略图中识别；标题由外部排版或确定性文字层绘制，不让生图模型生成中文。
- 辅助卡片只承担图标、流程、对比和场景表达，不放无意义小字。
- 保留手绘质感，但人物五官、手势、产品图标和主要关系必须清楚。

## 比例与交付

- AI 知识类项目默认交付 4:3 与 3:4 两版。
- 两个比例分别构图，不能从一个比例直接裁切另一个比例。
- 4:3 优先横向标题与角色/信息板平衡；3:4 优先纵向标题层级、角色动作和上下景深。
- 已确认参考图位于 `assets/covers/ai-knowledge-high-density`；参考视觉语言，不复制单条内容的标题和专属信息。
