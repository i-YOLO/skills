# 口播动画验收规范

## 视觉复核

检查全片每秒帧，以及每个场景、关键词、语义动作、预入场和转场的事件帧。允许正常弹入、弹出和淡入淡出；以下一律为缺陷：

- 文字或元素重叠、越界、不可读，或高亮后对比不足。
- 箭头、连线或装饰压住文字，或位置无法解释。
- 元素提前、滞后、闪退、单帧闪烁，或出现异常硬切。
- 最后一项动画尚未完成就开始退场，或完整状态停留不足 `min_settled_seconds`。
- SVG 路径尚未开始却提前显示箭头端点，或分支、返回、继续共用同一进度导致未来状态泄露。
- 模糊媒体、播放卡顿、未说明的长静止。
- 技术关系、流程方向或强调重点与口播不一致。

每段结尾需保留足以读清关键信息的画面。只有明确写入 `hold: true` 的信息停留可以豁免静止告警。

## 布局与资产复核

对带标题、正文和核心图形的页面，检查：

- 流程、卡片组、时间线和循环图的首个图形外边界是否与标题左边安全线对齐；不要把“视觉居中”误作水平居中。
- 正文、核心图形和注释是否留有合理间距；以 `1920×1080` 的 `48px` 为最低安全间距，且不得发生重叠。
- 流程图、卡片、标签和箭头是否遵循口播中的先后、对比、循环或分层关系；复用资产不得只因关键词相似就套用。
- 局部修复是否基于最终编码 MP4 检查了场景前/中/后帧及相邻转场前/中/后帧。
- 同组横向卡片、节点和连接线是否共享同一视觉中心线；不同卡片高度不能造成中心点偏移。
- 非字幕内容是否全部结束在 `y=820` 前；字幕是否位于固定 `x=140–1780、y=860–1040` 区域。
- 使用 `madem-ai-tech-dark-v1` 时，非字幕内容是否结束在 `y=1600` 前，字幕是否位于 `x=70–1010、y=1660–1870`。
- `character-motion` 是否只位于预留的左下/右下槽位，显示高度是否在 `280–340px` 建议范围内且不超过 `380px`。
- 左右角色是否读取独立帧，道具是否保持独立透明层；逐帧检查轮廓跳变、五官漂移、服装变形、颜色闪烁和单帧异常。
- 角色的准备、关键动作、结果与落定是否绑定真实口播词位；结果帧是否至少保持 1 秒。提前静止角色只能登记为非同步 `idle`，不能滥用预入场。

只有真实项目已验收、可参数化且不依赖专有素材的动画，才能进入可复用资产库。

## 同步复核

使用真实音频和词级时间轴，不按字数平均估时。语义动作在对应词位出现、词后完成，并在后续解释中以推进、高亮或焦点切换维持信息密度；不要整页先播完再干等口播。

短句临近转场时，仅容器、轮廓或弱化标签可提前最多 `0.75s` 淡入；完整语义文字、关键词和高亮必须在真实词位出现。每个同步项目都要通过动作覆盖、预入场、展示时长和概念所有权审计；脚本报告风险，文字可读性、空间关系与动效自然度仍需人工确认。

同步误差目标不超过半帧；超过半帧但不超过一帧为警告，超过一帧为失败，不得交付。

## 发布字幕与背景音乐复核

- 字幕可见文字必须来自已确认文案，词级 ASR 只用于时间；默认 49px 白字、纯黑 10px 描边、无阴影，所有画幅强制单行且不得小于 36px，起止吸附到最终帧率，且相邻字幕不重叠。
- 在最终编码字幕版上检查每秒帧、每条字幕的起始/中间/结束帧和场景转场，确认字幕没有遮挡关键信息、没有黑底面板、没有越界或不可读文字。
- 默认 BGM 只能在字幕版和同步报告通过后加入。检查混音报告的默认配置、项目内音乐指纹、完整解码和输出音轨规格。
- BGM 成片的视频流 MD5 必须等于字幕版参考视频流 MD5；同步仍以未混音乐的原始口播为参考，不能用混音时间替代词级证据。

## 技术复核

确认全片能够完整解码、宽高/帧率/编码符合目标、音轨状态正确，并保存检查报告和抽帧证据。

使用 `dense-tech-v1` 时还必须运行 `audit_motion_density.py`，确保没有超过 3 秒且无状态/环境动效支撑的口播空档、没有高注意力入场冲突、长场景具备至少三个状态节点，且最终编码视频没有静止候选。
